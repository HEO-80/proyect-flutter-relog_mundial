# World Clock Flutter App 🌍🕒

[ES] 
**World Clock** es una aplicación multiplataforma desarrollada con **Flutter** que permite a los usuarios consultar la hora en diferentes zonas horarias de todo el mundo. El proyecto destaca por su integración con APIs externas y una interfaz de usuario limpia y adaptativa.

[EN] 
**World Clock** is a cross-platform application built with **Flutter** that allows users to check the time in various time zones across the globe. The project showcases external API integration and a clean, adaptive user interface.

---

## ✨ Características | Features

### [ES]
* **Zonas Horarias Globales:** Consulta la hora exacta de ciudades en todos los continentes.
* **Interfaz Dinámica:** Cambia el fondo de la aplicación según si es de día o de noche en la ciudad seleccionada.
* **Consumo de API:** Integración con servicios REST para obtener datos de tiempo en tiempo real.
* **Multiplataforma:** Compatible con Android, iOS y Web.

### [EN]
* **Global Time Zones:** Check the exact time for cities across all continents.
* **Dynamic UI:** The background changes based on whether it is daytime or nighttime in the selected city.
* **API Integration:** Fetches real-time data using REST API services.
* **Cross-platform:** Support for Android, iOS, and Web.

---

## 🛠️ Stack Tecnológico | Tech Stack
* **Framework:** Flutter 3.x
* **Language:** Dart
* **API:** World Time API (o la que hayas usado)
* **Packages:** `http`, `intl` (para formateo de fechas).

## 🏗️ Estructura de Código | Code Structure
La lógica principal reside en la carpeta `lib/`:
* `/pages`: Contiene las pantallas principales (`home`, `loading`, `choose_location`).
* `/services`: Lógica para realizar las peticiones HTTP y procesar los datos de la zona horaria.
